# Raw LinkedIn data (local only)

Download **LinkedIn Job Postings (2023–2024)** from:
https://www.kaggle.com/datasets/arshkon/linkedin-job-postings

Keep the original CSV files in this directory **locally**. Raw datasets are excluded from version control. Do not commit the complete `postings.csv`, `companies.csv`, or the large relationship tables to this public repository.

Expected input tables:
- postings.csv or job_postings.csv (main postings table; see Kaggle download)
- companies.csv, company_industries.csv, company_specialities.csv, employee_counts.csv
- benefits.csv, job_industries.csv, job_skills.csv, salaries.csv
- industries.csv, skills.csv

A limited set of public reference labels is versioned in `data/reference/`; it is not a substitute for the original data.

Run `python scripts/prepare_data.py --input data/raw --output data/processed` after downloading and arranging the source files. The script reads the original tables, checks keys, and creates reproducible local subsets. No data are generated by guessing missing records.
