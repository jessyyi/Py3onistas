# Sample data

Use this folder only for small, deliberately selected **public, non-sensitive** examples that demonstrate the schema. Do not treat convenience samples as representative of the U.S. job market.

The team's current 100-row sample of postings is available in the project conversation but has not been committed here. Main job descriptions and all large raw CSVs belong in ignored `data/raw/`.

The primary reproducible analysis outputs are written locally to ignored `data/processed/`.
