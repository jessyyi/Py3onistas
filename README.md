
# JobScope

**Job Market Intelligence & Personalized Career Recommendation System**

NYU DS-GA 1007 — Programming for Data Science, Fall 2026

**Team:** Py3onistas  
**Members:** Jessy, Aileen, Damir

## Project Overview

JobScope analyzes historical U.S. job postings and develops an interpretable content-based recommendation system.

## Research Questions

1. Job Market Intelligence
2. Candidate–Job Matching
3. Personalized Job and Career Category Recommendation

## Methodology

- Data cleaning and exploratory analysis
- Skill extraction and TF-IDF
- Cosine similarity and hybrid matching
- Top-K job recommendations
- Career category discovery
- Human relevance evaluation

## Dataset

LinkedIn Job Postings (2023–2024), available on Kaggle.
